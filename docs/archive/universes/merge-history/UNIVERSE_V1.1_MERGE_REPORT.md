## 3. Pass 3 — Corrections Applied

### Research

- **Canonical formula.** §1 quoted a compact triad — *"Work shows outcomes. Research shows understanding. Lab shows tests."* — that predates and differs from the approved cross-district formula. Corrected to *"Work demonstrates capability. Research develops understanding. Lab tests and transforms."*
- **Hierarchy.** v1.0 itself stated the Question/Artifact relationship two incompatible ways: §7.4 collapsed them into "Question or Artifact," while §13.1 — titled, in v1.0's own words, "Approved hierarchy" — showed them as siblings under Research Line. Two further v1.0 passages (§9.4's orientation model, §16.4's stable anchors) omitted Question from the hierarchy entirely. The v1.1 draft had inherited this inconsistency, additionally mistranscribing v1.0 §13.1's sibling tree as a linear `Question → Artifact` chain in its own Organization Model section. **Corrected:** every hierarchy statement in the document — Experience Narrative (§6), Navigation (§8), Organization Model (§10), and Scalability (§15) — now uses v1.0 §13.1's own labeled "Approved hierarchy": Question and Artifact as siblings under Research Line, with a tree diagram and the inline form `Research Universe → Territory → Research Line → Question / Artifact`. A clarifying sentence was added: "Questions and artifacts are sibling entities within a Research Line. An artifact may address, document, challenge, or connect to one or more questions." No content model was invented; this restores v1.0's own labeled-approved structure uniformly.

### Art

- **Layout count.** v1.0 §18 contains twelve layout types (§18.1–18.12) plus one responsive-transformation principle (§18.13) — thirteen subsections, not thirteen layouts. The Merge Note had miscounted these as "thirteen named Chamber layouts." Corrected to: "Twelve layout types and their responsive principle were consolidated into one layout table and one responsive rule." No layout type was added or removed — the table still contains exactly twelve rows.
- **Media-disclosure obligations restored.** v1.0 §23 sets six distinct disclosure obligations (digital, generative, interactive, performative, ephemeral, process-based) plus a shared preservation-state vocabulary. These had been compressed into one undifferentiated paragraph, losing obligations that are not interchangeable (e.g., data-collection disclosure for interactive work has no equivalent in ephemeral work's trace/testimony/reconstruction disclosure). Restored as a compact table in §17 — one row per work type, the unified governing principle kept as the section's lead sentence — plus the six-state preservation vocabulary (Live, Partially functional, Documented, Reconstructed, Emulated, No longer reproducible). ART-16, ART-17, ART-23, and ART-24 were checked against the restored table; all remain consistent with no wording change needed. No new decision ID was added — this is treated as clarification of existing decisions, per this task's instruction.

### About

- **Content-model count.** v1.0 §28 contains twelve record types (Author Profile, Biography, Timeline Event, Experience Entry, Education Entry, Value, Method, Credential, Collaborator or Institution, Current State, Professional Document, Contact Route). The Merge Note and the §28 introduction had both said "thirteen." Corrected to "twelve" in both places. The table itself already contained the correct twelve rows and required no change — only the surrounding factual claims were wrong.
