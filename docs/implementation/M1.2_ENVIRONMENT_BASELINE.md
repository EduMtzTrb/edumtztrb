## Changes Made

1. **Runtime declaration** — added `"engines"` to `package.json`:
   ```json
   "engines": {
     "node": ">=22.13.1 <23.0.0",
     "npm": ">=10.9.2 <11.0.0"
   }
   ```
   Range chosen (not an exact pin) to allow patch-level updates within the same major version already verified by M1.1, while rejecting a materially different Node/npm major. `next` 16.3.0 itself only requires Node `>=20.9.0`; this repository's declared floor is the version actually verified working (v22.13.1), per the M1.1 audit's own recommendation, not an arbitrary minimum.
2. **`.nvmrc`** — added, containing `22.13.1`, so `nvm use` (or equivalent) resolves to the exact verified version.
3. **`.npmrc`** — added, containing `engine-strict=true`, so `npm install`/`npm ci` hard-fail on a Node/npm version outside the declared `engines` ranges instead of silently proceeding.
4. **`README.md`** — fully replaced the generic `create-next-app` boilerplate with project-specific content: prerequisites (Node/npm versions, npm-only policy), install command (`npm ci`), all six documented commands (dev/build/start/lint/format/format:check), an explicit statement that no typecheck or test script exists yet (and why), and the environment-variable convention (below).
5. **Environment-variable convention** — documented in `README.md` under "Environment variables": no variables exist or are required yet; `.env.example` is intentionally not created (see below); when a future work package needs its first real variable, it must go through `.env.example` (committed, placeholder values) / `.env.local` (git-ignored, real values), with `NEXT_PUBLIC_` reserved for values genuinely safe to expose to the browser, and no variable may be added speculatively — it must be required by an already-approved governing document at the time it's introduced.
6. **`package.json`** — no dependency versions changed; only the `engines` field was added.

## Environment-Variable Policy

- **Current state:** zero environment variables are required to install, run, lint, format, or build this repository. Confirmed by a repository-wide search of `src/` for `process.env` — no matches.
- **Decision:** `.env.example` was **not** created. Per this task's explicit constraint ("Create `.env.example` only if environment variables are actually required now" / "Do not invent placeholder API keys or speculative services"), creating one now would document variables that don't exist and none of the approved governing documents (Design System, Animation System, Platform Specification, Universe Specification Set, Cross-Universe System Requirements) require any for Milestone 1.
